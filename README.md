## Setup

```
# backend
cd server
npm install
npm run seed     # inserts 10 sample books + a test user
npm run dev

# frontend (separate terminal)
cd client
npm install
npm run dev
```

Then open http://localhost:5173.

BookStore - Book Selling Website

A modern and responsive book-selling e-commerce website built with React, TypeScript, and React Router.

This project demonstrates how to build a real-world frontend application with reusable components, routing, TypeScript, and an e-commerce shopping experience.

## 🚀 Live Demo

🔗 [View Live Demo]http://localhost:5173


 Features

Browse books
View book details
Client-side routing with React Router
Responsive design for desktop, tablet, and mobile
Reusable React components
TypeScript for type-safe development
Clean and user-friendly interface
